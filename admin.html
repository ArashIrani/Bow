منشور v2.4 (Serverless CMS)
ذخیره‌سازی مستقیم در GitHub REST API
امنیت دسترسی بدون سرور: توکن شخصی گیت‌هاب (Personal Access Token) شما درست مانند کلید خانه شماست. این توکن منحصراً درون مرورگر این رایانه نگهداری می‌شود و هیچ سرور میانی به آن دسترسی ندارد. هنگام اتمام کار در رایانه‌های اشتراکی، حتماً از دکمه «خروج امن» استفاده کنید.
